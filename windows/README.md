# GlassDock: собственный док с папками

[Скачать GlassDock 0.2.0 Preview для Windows x64](https://github.com/loschd22211/drag-5-voopoo/releases/download/glassdock-v0.2.0/GlassDock-0.2.0-win-x64.zip)

Сборка проверена GitHub Actions на Windows: run 41106028761. Опубликован отдельный
предварительный релиз, не стабильная версия. Интерактивный UI и расход ресурсов на
компьютере пользователя ещё не проверены.

Скачать, проверить фиксированный SHA256 и распаковать без установки можно скриптом
`download-glassdock.ps1`. Он не запускает EXE, открывает только папку результата.
Администратор не нужен. Путь — пользовательская папка Downloads, отдельная папка
с датой и временем, без удаления прежних загрузок.

Запустить `App/GlassDock.exe` вручную. `+` создаёт группу, `+ Ярлыки` добавляет
приложения, `+ Папка` добавляет путь к папке, а не вложенную группу. Для ярлыков
можно открыть `Win+R` → `shell:Programs` или `shell:Common Programs`. Файлы можно
перетащить из Проводника на группу. Имя группы редактируется в заголовке.
Закрыть: ПКМ по фону дока → «Закрыть GlassDock» или Alt+F4.

Фон полупрозрачный, без настоящего размытия стекла. Обои и Windows не изменяются.
Не запускать два дока одновременно, если они мешают друг другу. Пока не добавлять
GlassDock в автозагрузку. Не обходить предупреждения защиты ради неподписанного EXE.

Подробности и ограничения: [GlassDock/README.md](GlassDock/README.md).
