# Windows Glass — бесплатное оформление

Цель: док снизу, округлые иконки, стеклянные поверхности и виджеты на рабочем столе. Без платных программ, изменения обоев, отключения защиты или системных служб.

## Устройство и границы проверки

По данным пользователя: Windows 11 Pro 26H2, сборка 26300.9818; RTX 3070, i5-12400, 16 ГБ RAM, монитор 165 Гц. Совместимость именно с этой сборкой **не проверена**. Здесь нет доступа к Windows пользователя, реального теста установки или производительности.

## Основной кандидат: Seelen UI

- Исходники: https://github.com/eythaann/Seelen-UI
- Официальные установщики: https://github.com/eythaann/Seelen-UI/releases/latest
- Лицензия проекта: AGPL-3.0. Используем бесплатную открытую программу, не взломанные платные аналоги.
- В README проекта заявлены док, темы, лаунчер и виджеты рабочего стола. Точное наличие подходящих бесплатных часов, календаря, погоды и папок-групп в выбранном релизе нужно проверить. Не обещаем поведение папок как на iPhone или полную замену анимаций Windows.
- Резерв для виджетов: https://github.com/rainmeter/rainmeter (GPL-2.0). Пока не устанавливаем второй движок: сначала проверяем возможности Seelen, чтобы не плодить фоновую нагрузку.

Чужой исходный код и большие установщики не включены в этот репозиторий. Их копирование не настраивает Windows и усложняет обновления. Вместо этого есть небольшой загрузчик официального релиза.

## Скачать

Самый простой способ: открыть страницу релиза выше и выбрать **x64-setup.exe**, не ARM64. Сохранить в «Загрузки». Source code ZIP — это исходники, не готовая программа.

Либо открыть PowerShell в папке распакованного проекта (Проводник → адресная строка → `powershell`) и выполнить:

```powershell
cd "windows"
powershell -NoProfile -File .\download-seelen.ps1
```

Если политика PowerShell запрещает запуск, использовать ручную загрузку, не менять политику системы. Загрузчик спрашивает `YES`, сохраняет установщик в `%USERPROFILE%\Downloads\Windows-Glass`, не перезаписывает существующие файлы и **не запускает установку**. Проверяет размер и SHA256, если GitHub публикует digest, выводит статус цифровой подписи. Совпадение хеша не является аудитом безопасности. При ошибке `.partial` сохраняется для осмотра, запускать его нельзя. Не обходить предупреждения защиты.

## Настройка по одному шагу

1. Проверить, что в расширенных параметрах дисплея Windows действительно выбрано 165 Гц. Частоту не менять вслепую.
2. Записать исходное состояние эффектов анимации и прозрачности Windows. Для желаемого вида они должны быть включены; пока ничего не менять автоматически.
3. Перед ручной установкой сохранить важную работу. После установки сначала проверить возможность выхода из Seelen и возвращения обычного рабочего стола. Пока не включать автозапуск.
4. Настроить один док внизу. Проверить его поверх окон и в полноэкранной игре, только затем настраивать скрытие стандартной панели задач. Не отключать Explorer.
5. Не включать тайлинг окон, замену обоев и дополнительные эффекты, если они не нужны. Выбрать бесплатную тему с размытием и округлением, проверить доступность групп приложений в интерфейсе.
6. Добавлять часы, календарь и погоду по одному. Погода может требовать интернет, город и отдельный API-ключ: не считать любую тему бесплатной без проверки условий. Не публиковать ключи в репозитории.
7. Проверить расход RAM/CPU/GPU в простое и игру в одинаковых условиях до/после. При рывках сначала закрыть оформление и сравнить. Не обещать нулевую нагрузку или рост FPS.

## Откат

Выйти из Seelen, убрать его из автозагрузки, если она была включена. При необходимости удалить через «Параметры → Приложения → Установленные приложения». Если менялось автоскрытие штатной панели задач, вернуть прежнее значение. Не удалять папки конфигурации до проверки восстановления. При проблемах перезапустить «Проводник Windows» через Диспетчер задач, сохранив работу с файлами заранее.

Загрузчик ничего из этого не меняет: его откат — удалить только скачанный установщик, когда он больше не нужен.
