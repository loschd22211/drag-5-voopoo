# GlassDock — первый самостоятельный прототип

Нативное Windows-приложение на C# / WPF (.NET 8), без Electron, браузера,
локального сервера, сетевого API, телеметрии, таймеров опроса системы и прав администратора.
Код написан отдельно: исходники Seelen UI и WinLaunch не копировались.

## Уже реализовано в исходниках

- Нижний док с группами, до 10 групп в первой версии.
- Нажатие на группу раскрывает округлое окно с ярлыками непосредственно над доком.
- Переименование в поле заголовка; сохранение при потере фокуса.
- Добавление локальных ярлыков/программ/файлов и папок через диалог.
- ПКМ по ярлыку или группе: удаление только из конфигурации, не с диска.
- Открытие локальных элементов через штатную оболочку Windows.
- Анимация раскрытия и закрытия, 180 мс, с уважением к отключению анимации Windows.
- Настройки в `%LOCALAPPDATA%\GlassDock\groups.json`.
- Escape / «Свернуть» закрывают группу, ПКМ по фону дока → выход.
- Не меняет обои, Explorer, панель задач, автозапуск или настройки Windows.

Это не готовая замена всех функций двух оболочек. Пока вместо настоящего размытого
стекла используется полупрозрачный фон; вместо извлечённых иконок — текстовые кнопки.
Нет drag-and-drop, системного трея, глобальных горячих клавиш, полноценной поддержки
нескольких мониторов и автоматического скрытия в играх. По умолчанию окно не Topmost,
чтобы не перекрывать игру. Не запускать неизвестные файлы через добавленные ярлыки.

## Сборка

На Windows с .NET 8 SDK, из корня репозитория:

```powershell
cd windows\GlassDock
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

Запускать `publish\GlassDock.exe`. Self-contained сборка содержит .NET: больше на
диске, зато отдельная установка runtime не нужна. При первом запуске возможна
распаковка библиотек .NET в пользовательскую временную папку.

Также добавлен workflow `.github/workflows/glassdock.yml`: после публикации ветки
его можно запустить в GitHub Actions и скачать артефакт `GlassDock-win-x64`.
Это не ссылка на уже готовый релиз. Бинарник не подписан сертификатом издателя;
предупреждения SmartScreen не следует автоматически обходить.

## Проверки и ограничения

В текущей Linux-среде нет dotnet/Windows: сборка и UI пока **не проверены**.
Workflow предназначен для проверки компиляции; он не заменяет реальное тестирование
на Windows 11 26H2. Нельзя обещать фиксированный расход RAM, отсутствие лагов или
нулевую нагрузку. До использования вместо Seelen проверить запуск, сохранение,
повторное открытие, запуск ярлыка, удаление группы, Escape и поведение в игре.

Для сравнения нагрузки открыть Диспетчер задач: измерить CPU и память в простое,
при анимации и после закрытия окна группы. Анимации не должны постоянно работать.

## Удаление

Закрыть GlassDock через контекстное меню дока или Alt+F4. Удалить только папку с
его распакованной сборкой. Конфигурацию можно сохранить; удалять её необязательно.
Системные настройки восстанавливать не требуется: приложение их не меняет.

Seelen UI удалять отдельно штатно: `Win+R` → `appwiz.cpl` → Seelen UI → удалить.
Это не команда удаления GlassDock. Не применять широкое удаление папок/реестра и
не удалять Seelen автоматически до проверки замены.
