Gemini на долгое нажатие кнопки питания

OnePlus Ace 5 / 13R и другие OxygenOS / ColorOS, включая китайские сборки

проверяю adb… устройство не выбрано

1 Подключение телефона

Включи на телефоне «Для разработчиков» → «Отладка по USB», подключи кабелем и подтверди запрос отпечатка на экране. Либо подключись по Wi-Fi.

Подключение по Wi-Fi (Android 11+)

На телефоне: «Для разработчиков» → «Отладка по Wi-Fi» → «Подключение с помощью кода». Получишь адрес вида 192.168.1.50:37123 и 6-значный код. 


      


      

        
2 Диагностика

        

          Собираю модель, прошивку, установленные Google-сервисы, текущего помощника и доступные
          системные экраны. Ничего не меняю.
        

        

          
          
        

        

      


      

        
3 Назначить помощника

        

          Ставлю Google/Gemini как цифрового помощника по умолчанию через ADB. Это те самые два
          системных параметра, которые меняет пункт «Приложения по умолчанию → Цифровой помощник».

5 Кнопка питания: найденные системные экраны

        

          На китайской ColorOS пункт «Цифровой помощник» иногда спрятан или не срабатывает. Здесь
          список экранов, которые реально есть на твоём устройстве, — открой нужный и переключи
          вручную.
        

        

      


      

        
6 Что именно меняет настройка

        

          Сними снимок, переключи кнопку питания руками на телефоне, сними второй — и увидишь точные
          ключи и значения, которые изменились. Полезно, чтобы понять, работает ли настройка на
          этой прошивке вообще.
        

        

          
          
        

        

      


      

        
Журнал команд

        
        

      

    


    

      

        Инструмент работает локально и общается только с твоим телефоном через adb. Никакие данные
